# Swahili glossary (for owner / native-speaker review)

The website uses these Swahili terms **consistently** (Phase 1.1, slice 4). Please check them and
mark any you would change — then every place that uses the term is updated together.

Status: **draft — needs review by a native Swahili speaker.**

## How content in the admin is checked

Lists in the admin show **"Swahili missing"** on any item whose English fields have text but the
Swahili ones are empty, and the editor names the exact fields. Visitors never see a blank: the site
shows English until the Swahili is added (FR-9).
